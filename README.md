🎬 Movie Ticket Booking System

A Java-based console application for booking, canceling, and managing movie tickets across multiple theatres and screens.
This project demonstrates object-oriented programming (OOP) concepts such as classes, objects, encapsulation, and collections, while solving a real-world problem.

📌 Features

🎟 User Management

Register as a new user

Login with credentials

🎥 Theatre & Movie Management

Multiple theatres supported

Each theatre can have multiple screens

Movies with show timings

🪑 Seat Booking System

Choose seats from a seating layout (rows & columns)

Validates seat availability

Prevents double-booking

🔄 Ticket Operations

Book tickets

Cancel booked tickets

Track booking history

💰 Pricing & Revenue

Base price for each movie ticket

Calculates total revenue per show

🛠 Technologies Used

Language: Java (Core Java, OOP, Collections)

Data Structures: Arrays, 2D arrays, ArrayList, HashMap

Concepts: Encapsulation, Classes, Objects, Methods, Loops, Exception Handling

🚀 How to Run

Clone the repo:

git clone https://github.com/your-username/MovieTicketBookingSystem.git
cd MovieTicketBookingSystem


Compile the Java file:

javac MultiTheatreBookingSystem.java


Run the program:

java MultiTheatreBookingSystem

📖 Example Flow

User registers/logs in

User selects a theatre and movie

Seats are displayed (rows × columns grid)

User selects seats to book

System updates availability and confirms booking

User can cancel tickets if needed
